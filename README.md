# OPTIMIS Suite para Windows

Aquí solo se publican los **instaladores** de la app de escritorio de OPTIMIS Suite.
El código de OPTIMIS es privado y la app no contiene contraseñas ni datos: solo abre la
pantalla de acceso de OPTIMIS.

## Instalar (la primera vez)

1. Descarga **[OPTIMIS-Setup.exe](https://github.com/nutmiguelelias-blip/optimis-escritorio/releases/latest/download/OPTIMIS-Setup.exe)** (siempre es la última versión).
2. Ábrelo. Si Windows muestra «Windows protegió tu PC», pulsa **Más información → Ejecutar de todas formas**.
3. Listo. Desde ese momento **la app se actualiza sola**: no hay que volver a descargar nada.
